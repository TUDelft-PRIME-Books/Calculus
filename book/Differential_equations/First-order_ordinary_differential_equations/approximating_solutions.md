# Approximating solutions

## Introduction

An initial value problem is a mathematical description (as in Equation {eq}`Eq:ApproximatingSolutions:IVP`) usually of a time-dependent problem. The conditions, necessary to determine a unique solution, are given at the initial time, $t_0$, and are called _initial conditions_.

As an example, we consider a water discharge from a storage reservoir through a pipe ({numref}`Fig:ApproximatingSolutions:stuwmeer`). The water is at rest until, at $t_0 = 0$, the latch is instantaneously opened. This results in an imbalance of forces and gravity causes a gradual development of the flow of water. If this flowing water is used to generate electricity, for example like the [Picote Dam](https://en.wikipedia.org/wiki/Picote_Dam), then it is important to know how long it will take before the turbines work at full power.

:::{figure} Images/Fig-NumericalMethods-stuwmeer.png
:name: Fig:ApproximatingSolutions:stuwmeer

The storage reservoir, the drain pipe and the latch in closed position.

:::

This process is described by the non-linear initial value problem

:::{math}
:label: Eq:ApproximatingSolutions:ivp_intro

\left\{ 
\begin{array}{rl}
	\frac{dq}{dt} \hspace{-0.3cm}&= p(t) - aq^{2}, \quad t \geq 0,  \\[2ex]
	q(0) \hspace{-0.3cm}&= 0.
\end{array}
\right.

:::

In this problem, $q$ is the mass flow rate, measured in $\text{m}^{3}/\text{s}$, $p$ is the driving force, which is equal to 

$$
\frac{\text{force/length}}{\text{density}} \quad\text{and measured in}\quad \frac{\text{N}/\text{m}}{\text{kg}/\text{m}^{3}}= \frac{\text{m}^{3}}{\text{s}^{2}},
$$

and $aq^{2}$ is the friction measured the same as $p$. The driving force depends --among other things-- on the water level in the reservoir. If $p(t)=p_0$ in Equation {eq}`Eq:ApproximatingSolutions:ivp_intro`, the following solution can be found:

$$
q(t)= \sqrt{\frac{p_{0}}{a}} \tanh \left(t \sqrt{ap_{0}}\right).
$$

For general functions $p$, an exact formula for the solution cannot be obtained. In that case, a numerical method can be used to approximate the solution.

For many initial value problems it is impossible to determine a solution explicitly. Although there are generally applicable techniques to find qualitative properties of the solution, these properties usually provide insufficient quantitative information. For that purpose, numerical methods are designed to approximate the solution. Most numerical methods are designed for first-order initial value problems. Numerical time-integration methods that can be applied directly to higher-order initial value problems do exist but are not treated here.

In this section, several methods will be presented that can be used to approximate the solution to the initial value problem based on the scalar first-order differential equation


::::{math}
:label: Eq:ApproximatingSolutions:IVP

\left\{ 
\begin{array}{rl}
	y^\prime \hspace{-0.3cm} &= f(t, y), \quad t \geq t_0, \\
	y(t_0) \hspace{-0.3cm}&= y_0.
\end{array}
\right.

::::

A differential equation is a rule that provides the slope of the tangent of a solution curve at each point in the $(t,y)$-plane. A specific solution curve is selected by specifying a point through which that solution curve passes, which in our case is $(t_0,y(t_0))=(t_0,y_0)$. A formal expression for the solution curve through the point $(t_0, y_0)$ is generated by integrating the differential equation over $t$ from $t_0$ to some time $T$:

$$
\int_{t_0}^{T}y'(t)\,dt=\int_{t_0}^{T}f(t,y(t))\,dt.
$$

Using {prf:ref}`Thm:Integration:FundamentalTheoremPart2`, we find

$$
y(T) = y(t_0) + \int_{t_0}^T f(t, y(t))\,dt.
$$

Because the unknown function $y$ appears under the integral sign, this equation is called an _integral equation_. Although the integral equation is as difficult to solve as the original initial value problem, it provides a better starting point for approximating the solution.

In order to approximate the solution to the integral equation numerically, the time axis is divided into a set of discrete points $t_n = t_0 + n \Delta t$, $n=0,1,\ldots$. The solution at each time step is computed using the integral equation. Assume that the solution to the differential equation at time $t_n$ is known, and denoted by $y_n = y(t_n)$. Then, the solution at $t_{n+1}$ is equal to 

:::{math}
:label: Eq:ApproximatingSolutions:int_eq

y_{n+1} = y_n + \int_{t_n}^{t_{n+1}} f(t,y(t))\ dt.

:::

The numerical time-integration methods that are presented in this section can be characterised by the approximation of the integral term $\displaystyle\int_{t_n}^{t_{n+1}} f(t, y(t))\ dt$: different numerical integration rules can be used. 

The numerical approximation of the solution at $t_n$ is denoted by $\tilde{y}_n$, $n=0,1,\ldots$, where $\tilde{y}_0 = y_0$.

## Forward Euler method

First, the _Forward Euler method_ will be presented, which is the most simple, earliest, and best-known time-integration method. In this method, an approximation of the integral in Equation {eq}`Eq:ApproximatingSolutions:int_eq` is obtained by using the left Rectangle rule, see {prf:ref}`Def:ApproximatingIntegrals:simple_rules`.

::::{math}
:label: Eq:ApproximatingSolutions:rkl1

y_{n+1} \approx y_n + (t_{n+1}-t_n)f(t_n,y_n).

::::

This integral is illustrated in {numref}`Fig:ApproximatingSolutions:leftRectangle`.

:::{applet}
:url: calculus/approximating_solutions/left_Rectangle_rule_applied_to_an_ivp
:name: Fig:ApproximatingSolutions:leftRectangle
:class: dark-light

The left Rectangle rule applied to $f(t,y(t))$. \
Remark: The blue line represents a possibility for $f(t,y(t))$, assuming we would have known $y(t)$.
:::

Note that $f(t_n, y_n)$ is the slope of the tangent in $(t_n, y_n)$. The numerical approximation of the solution at $t_{n+1}$, denoted by $\tilde{y}_{n+1}$, is computed by

::::{math}
:label: Eq:ApproximatingSolutions:FE

\tilde{y}_{n+1} = \tilde{y}_n + \Delta t f(t_n, \tilde{y}_n),

::::

in which $f(t_n, \tilde{y}_n)$ is the slope of the tangent in $(t_n, \tilde{y}_n)$.

This procedure leads to a sequence $((t_n,\tilde{y}_n))$, $n=0,1,\ldots$ of approximation points.

To summarise:

::::{prf:definition}
:label: Def:ApproximatingSolutions:FE

Consider the general initial value problem Equation {eq}`Eq:ApproximatingSolutions:IVP`. Define $\tilde{y}_n$ as the numerical approximation of $y(t_n)$.

Then the **Forward Euler method** is defined by the discrete dynamical system

$$
\left\{\begin{array}{rclll}
	\tilde{y}_{n+1} & = & \tilde{y}_n+\Delta t f(t_n,\tilde{y}_n), & \text{for} & n\geq 0, \\
	\tilde{y}_0 & = & y_0,
\end{array}\right.
$$

where $t_{n}=t_0+n\Delta t$.

::::

Because $\tilde{y}_{n+1}$ can be computed directly from Equation {eq}`Eq:ApproximatingSolutions:FE`, the Forward Euler method is called an _explicit method_.

::::{prf:example} 
:label: Ex:ApproximatingSolutions:FE

Consider the following initial value problem:

$$
\left\{\begin{array}{rclll}
	y'(t) & = & -\frac15ty^2, & \text{for} & t\geq -2, \\
	y(-2) & = & 1.
\end{array}\right.
$$

We will perform two time steps with the Forward Euler method with $\Delta t=1$.

First, we note that $t_0=-2$, $\tilde{y}_0=y(t_0)=y(-2)=1$ and $f(t,y)=-\frac15ty^2$.

Then we calculate $\tilde{y}_1$, which is an approximation of $y_1=y(t_1)=y(t_0+\Delta t)=y(-2+1)=y(-1)$:

$$
\begin{align*}
	\tilde{y}_1 &= \tilde{y}_0 + \Delta t f(t_0,\tilde{y}_0) \\
	&= 1 + 1\cdot\left(-\frac15\cdot(-2)\cdot(1)^2\right) \\
	&= 1.4.
\end{align*}
$$

Then we calculate $\tilde{y}_2$, which is an approximation to $y_2=y(t_2)=y(t_0+2\Delta t)=y(-2+2\cdot1)=y(0)$:

$$
\begin{align*}
	\tilde{y}_2 &= \tilde{y}_1 + \Delta t f(t_1,\tilde{y}_1) \\
	&= 1.4 + 1\cdot\left(-\frac15\cdot(-1)\cdot(1.4)^2\right) \\
	&= 1.792.
\end{align*}
$$
We can keep doing time steps, and if we do, we would obtain the approximations shown in {numref}`Fig:ApproximatingSolutions:eulerPolygon`. Use the slider to see more/less approximations.

Consider again {prf:ref}`Def:ApproximatingSolutions:FE`. Since $ \tilde{y}_{0} $ is provided and we know how to compute the next instance of  $ \tilde{y} $ using the rule $ \tilde{y}_{n + 1} = \tilde{y}_{n} + \Delta t f(t_{n}, \tilde{y}_{n}) $ for $ n \geq 0 $, it then all boils down to choosing the time step $ \Delta t $. The value of $\Delta t$ can be very important, which the next example shows. 

::::{prf:example}
:label: Ex:ApproximatingSolutions:EX2

Consider the initial value problem

:::{math}
:label: Eq:ApproximatingSolutions:EX2

\left\{\begin{array}{rclll}
	y' & = & \frac7{10}\left(1-\frac{y}{750}\right)y-20, & \text{for} & t\geq 0, \\
	y(0) & = & 30.
\end{array}\right.

:::

Any numerical approximation should resemble in some sense the exact solution of the initial value problem. Let us apply the Forward Euler method using $\Delta t=8$ to this initial value problem and stop at $t=64$. This gives the results in {numref}`Fig:ApproximatingSolutions:Euler8`.

For this initial value problem the exact solution is known. Generally it is not possible to compare a numerical approximation to the exact solution of the initial value problem. At such times the slope or directional field are a good alternative to asses the accuracy of a numerical approximation. As you can see, the shape of the numerical approximation deviates wildly from the direction of the slope field. As such this numerical approximation will not resemble the exact solution. So let us see what happens when $\Delta t=4$. We did the computations again and you can see the results in {numref}`Fig:ApproximatingSolutions:Euler8` if you change the slider for $\Delta t$ to $4$.

The numerical results now somewhat follows the slope field, but still deviates a lot. So let us try two more times, once with $\Delta t=2$ and a final time with $\Delta t=1$. Use the slider for $\Delta t$ in {numref}`Fig:ApproximatingSolutions:Euler8` to investigate these results.

If we compare all the results, we can definitely see that for $\Delta t=1$ the numerical approximations finally behaves in a manner predicted by the slope field. Using the slope field gives a crude estimate for accuracy and we can only say the approximation is close (enough) to the exact solution.

::::

So always remember to check your results and adjust $\Delta t$ if needed. For each of the methods in this chapter you should remember this.

## Backward Euler method

The _Backward Euler method_ is obtained by using the right Rectangle rule to approximate the integrals, see {prf:ref}`Def:ApproximatingIntegrals:simple_rules`. At time $t_{n+1}$, the solution is approximated by

$$
y_{n+1} = y_n + \int_{t_n}^{t_{n+1}} f(t,y(t))\ dt \approx y_n + \Delta t f(t_{n+1}, y_{n+1}). 
$$

The numerical approximation at $t = t_{n+1}$ equals

::::{math}
:label: Eq:ApproximatingSolutions:BE

\tilde{y}_{n+1} = \tilde{y}_n + \Delta t f(t_{n+1},\tilde{y}_{n+1}).

::::

Note that the unknown $\tilde{y}_{n+1}$ also occurs on the right-hand side. For that reason, the Backward Euler method is called an _implicit method_. If $f$ depends linearly on $y$, then the solution to Equation {eq}`Eq:ApproximatingSolutions:BE` can be easily computed. 

For non-linear initial value problems, the solution to Equation {eq}`Eq:ApproximatingSolutions:BE` may be non-trivial. In that case, a numerical non-linear solver has to be applied, see {numref}`Sec:IterativeMethodsForVariousProblems`. This means that the Backward Euler method uses more computation time per time step than the Forward Euler method. However, the Backward Euler method also has some advantages, which you can learn about in a Numerical Analysis course.

To summarise:

::::{prf:definition}
:label: Def:ApproximatingSolutions:BE

Consider the general initial value problem from Equation {eq}`Eq:ApproximatingSolutions:IVP`. Define $\tilde{y}_n$ as the numerical approximation of $y(t_n)$.

Then the **Backward Euler method** is defined by the discrete dynamical system

$$
\left\{\begin{array}{rclll}
	\tilde{y}_{n+1} & = & \tilde{y}_n+\Delta t f(t_{n+1},\tilde{y}_{n+1}), & \text{for} & n\geq 0, \\
	\tilde{y}_0 & = & y_0,
\end{array}\right.
$$

where $t_{n}=t_0+n\Delta t$.

::::

::::{prf:example} 
:label: Ex:ApproximatingSolutions:BE

Consider the following initial value problem:

$$
\left\{\begin{array}{rclll}
	y'(t) & = & -\frac15ty^2, & \text{for} & t\geq -2, \\
	y(-2) & = & 1.
\end{array}\right.
$$

We will perform two time steps with the Backward Euler method with $\Delta t=1$.

First, we note that $t_0=-2$, $\tilde{y}_0=y(t_0)=y(-2)=1$ and $f(t,y)=-\frac15ty^2$.

Then we calculate $\tilde{y}_1$, which is an approximation of $y_1=y(t_1)=y(t_0+\Delta t)=y(-2+1)=y(-1)$:

$$
\begin{array}{rrcl}
&	\tilde{y}_1 &=& \tilde{y}_0 + \Delta t f(t_1,\tilde{y}_1) \\
\Rightarrow & \tilde{y}_1 &=& 1 + 1\cdot\left(-\frac15\cdot(-1)\cdot(\tilde{y}_1)^2\right) \\
\Rightarrow & \tilde{y}_1 &=& 1 + \frac15\cdot\left(\tilde{y}_1\right)^2 \\
\Rightarrow & 0.2\cdot\left(\tilde{y}_1\right)^2 - \tilde{y}_1 + 1 &=& 0 \\
\Rightarrow & \left(\tilde{y}_1\right)^2 - 5\tilde{y}_1 + 5 &=& 0 \\
\Rightarrow & \tilde{y}_1 &=& \frac52\pm\frac12\sqrt{5}. \\
\end{array}
$$

As you notice, we find two possible values for $\tilde{y}_1$, and the question is which we should take. We can expect that the value of $\tilde{y}_1$ is reasonably close to the value of $\tilde{y}_0=1$. Of the two values we found, this is

$$
\tilde{y}_1=\frac52-\frac12\sqrt{5}.
$$

Next we calculate $\tilde{y}_2$, which is an approximation to $y_2=y(t_2)=y(t_0+2\Delta t)=y(-2+2\cdot1)=y(0)$:

$$
\begin{array}{rrcl}
&	\tilde{y}_2 &=& \tilde{y}_1 + \Delta t f(t_2,\tilde{y}_2) \\
\Rightarrow & \tilde{y}_2 &=& \frac52-\frac12\sqrt{5} + 1\cdot\left(-\frac15\cdot(0)\cdot(\tilde{y}_2)^2\right) \\
\Rightarrow & \tilde{y}_2 &=& \frac52-\frac12\sqrt{5}.
\end{array}
$$

In this case we, luckily, only find one value for $\tilde{y}_2$.

We can keep doing time steps, and if we do, we would obtain the approximation shown in {numref}`Fig:ApproximatingSolutions:eulerPolygon-B`. Use the slider to see more/less approximations.

## Trapezoidal method

The _Trapezoidal method_ is constructed using the Trapezoidal rule to approximate the integral (see {prf:ref}`Def:ApproximatingIntegrals:simple_rules`). This means that 

$$
y_{n+1} = y_n + \int_{t_n}^{t_{n+1}} f(t,y(t))\ dt \approx y_n + \frac{\Delta t}{2}\left(f(t_n,y_n)+ f(t_{n+1},y_{n+1})\right).
$$

The approximation of the solution at $t = t_{n+1}$ equals

::::{math}
:label: Eq:ApproximatingSolutions:TM

\tilde{y}_{n+1} = \tilde{y}_n + \frac{\Delta t}{2}\left(f(t_n,\tilde{y}_n)+ f(t_{n+1},\tilde{y}_{n+1})\right).

::::

Note that the Trapezoidal method is also an _implicit_ method. 

::::{prf:example}
:label: Ex:ApproximatingSolutions:EX4-TR

We can apply the Trapezoidal method to the same initial value problem as in {prf:ref}`Ex:ApproximatingSolutions:FE`:

$$
\left\{\begin{array}{rclll}
	y'(t) & = & -\frac15ty^2, & \text{for} & t\geq -2, \\
	y(-2) & = & 1.
\end{array}\right.
$$

We will perform two time steps with the Trapezoidal method with $\Delta t=1$.

First, we note that $t_0=-2$, $\tilde{y}_0=y(t_0)=y(-2)=1$ and $f(t,y)=-\frac15ty^2$.

Then we calculate $\tilde{y}_1$, which is an approximation of $y_1=y(t_1)=y(t_0+\Delta t)=y(-2+1)=y(-1)$:

$$
\begin{array}{rrcl}
&	\tilde{y}_1 &=& \tilde{y}_0 + \dfrac{\Delta t}{2}\left( f(t_0,\tilde{y}_0) + f(t_1,\tilde{y}_1) \right) \\
\Rightarrow & \tilde{y}_1 &=& 1 + 0.5\cdot\left(-\frac15\cdot(-2)\cdot(1)^2-\frac15\cdot(-1)\cdot(\tilde{y}_1)^2\right) \\
\Rightarrow & \tilde{y}_1 &=& 1.2 + 0.1\cdot\left(\tilde{y}_1\right)^2 \\
\Rightarrow & 0.1\cdot\left(\tilde{y}_1\right)^2 - \tilde{y}_1 + 1.2 &=& 0 \\
\Rightarrow & \left(\tilde{y}_1\right)^2 - 10\tilde{y}_1 + 12 &=& 0 \\
\Rightarrow & \tilde{y}_1 &=& 5\pm\sqrt{13}. \\
\end{array}
$$

As you notice, similar to the result we got with the Backward Euler method in {prf:ref}`Ex:ApproximatingSolutions:BE`, we find two possible values for $\tilde{y}_1$, and the question is which we should take. We can expect that the value of $\tilde{y}_1$ is reasonably close to the value of $\tilde{y}_0=1$. Of the two values we found, this is

$$
\tilde{y}_1=5-\sqrt{13}.
$$

Next we calculate $\tilde{y}_2$, which is an approximation to $y_2=y(t_2)=y(t_0+2\Delta t)=y(-2+2\cdot1)=y(0)$:

$$
\begin{array}{rrcl}
&	\tilde{y}_2 &=& \tilde{y}_1 + \dfrac{\Delta t}{2} \left(f(t_1,\tilde{y}_1) + f(t_2,\tilde{y}_2)\right) \\
\Rightarrow & \tilde{y}_2 &=& 5-\sqrt{13} + 0.5\cdot\left(-\frac15\cdot(-1)\cdot(5-\sqrt{13})^2-\frac15\cdot(0)\cdot(\tilde{y}_2)^2\right) \\
\Rightarrow & \tilde{y}_2 &=& \dfrac{44}{5} - 2\sqrt{13}.
\end{array}
$$

In this case we, luckily, only find one value for $\tilde{y}_2$.

We can keep doing time steps, and if we do, we would obtain the approximation shown in {numref}`Fig:ApproximatingSolutions:trapezoidalPolygon`. Use the slider to show more/less approximations.

As you may notice, performing these computations by hand can be a lot of work for one time step, let alone for many time steps. Therefore we commonly use a computer to perform all of the calculations. To perform these calculations on a computer, might require some programming skills. The next example includes some code written in the programming language Python that applies our three methods to an initial value problem.

:::{prf:example-start}
:label: Ex:ApproximatingSolutions:ThetaMethod

Each of the three numerical time-integration methods in this section can be generalised to the $\theta$-method:
:::

:::{prf:definition}
:label: Def:ApproximatingSolutions:ThetaMethod

Consider the general initial value problem Equation {eq}`Eq:ApproximatingSolutions:IVP`. Define $\tilde{y}_n$ as the numerical approximation of $y(t_n)$.

Then the **$\theta$-method** is defined by the discrete dynamical system

$$
\left\{\begin{array}{rclll}
	\tilde{y}_{n+1} & = & \tilde{y}_n+(1-\theta)\Delta t f(t_n,\tilde{y}_n)+\theta\Delta t f(t_{n+1},\tilde{y}_{n+1}), & \text{for} & n\geq 0, \\
	\tilde{y}_0 & = & y_0,
\end{array}\right.
$$

where $t_{n}=t_0+n\Delta t$ and $\theta\in[0,1]$.
:::

Note that if $\theta=0$ the $\theta$-method is _explicit_ and otherwise _implicit_. Also,

- if $\theta=0$, the Forward Euler method is recovered;

- if $\theta=\frac12$, the Trapezoidal method is recovered;

- if $\theta=1$, the Backward Euler method is recovered.

The next code gives showcases the use of the $\theta$-method, where if the $\theta>0$, the solution of the implicit equation arising each time-step is approximated using the bisection method (see {numref}`Sec:IterativeMethodsForVariousProblems`). The initial problem we consider is

$$
\left\{\begin{array}{rclll}
	y'(t) & = & -\frac15ty^2, & \text{for} & t\geq -2, \\
	y(-2) & = & 1,
\end{array}\right.
$$

on the interval $[-2,3]$ with initially $\Delta t=0.01$.

:::{code-cell} python
---
tags: [auto-execute-page]
---
# Import numpy
import numpy as np
# Import the bisection method
from scipy.optimize import bisect as bisection
# import Matplotlib
import matplotlib.pyplot as plt 
# Set the value for theta
theta = 0.5
# define the function f(t,y) from the DE y'=f(t,y)
def f(t,y):
  return -0.2*t*(y**2)
# Set the initial condition y(t0)=y0
t0 = -2
y0 = 1
# Set the time step and the final time
DeltaT = 0.01
T = 3
# Set the region in which we expect the solution
# to remain for the bisection method
ymin = 0
ymax = 2
# Calculate the number of time steps (and update DeltaT if needed)
steps = int(np.ceil((T-t0)/DeltaT))
DeltaT = (T-t0)/steps
# Define a single time step with the theta method
# from tn to tn+DeltaT
def ThetaTimeStep(tn,yn,f,DeltaT,theta,ymin,ymax):
  if theta==0:
    # Apply Forward Euler method
    return yn + DeltaT*f(tn,yn)
  else:
    # Define the function of which we need to find the root
    zerofunc = lambda x : x - (yn + (1-theta)*DeltaT*f(tn,yn)
                         + theta*DeltaT*f(tn+DeltaT,x))
    # Find the root of this function
    ynext = bisection(zerofunc, ymin, ymax, xtol=1e-6*abs(ymax-ymin))
    return ynext
# Perform a loop over all time steps needed
# using pre-allocated arrays
tnum = np.linspace(t0,T,steps+1)
ynum = np.zeros_like(tnum)
ynum[0] = y0
for n in range(steps):
  ynum[n+1] = ThetaTimeStep(tnum[n],ynum[n],f,DeltaT,theta,ymin,ymax)
# Visualise the result
## Create the figure
fig, ax = plt.subplots()
ax.set_xlabel('$t$')
ax.set_ylabel('$y$')
## Add a coarse direction field
tvec = np.linspace(t0,T,21)
yvec = np.linspace(ymin,ymax,21)
Tvec,Yvec = np.meshgrid(tvec,yvec)
Uvec = np.ones_like(Tvec)
Vvec = f(Tvec,Yvec)
ax.quiver(Tvec,Yvec,Uvec,Vvec,angles='xy',pivot='middle')
## Add the numerical approximation
plt1 = ax.plot(tnum, ynum)
:::

## Accuracy

So far, we have presented three numerical time-integration methods. In obtaining these numerical time-integration methods, we have used the composite integration rules (see {ref}`Sec:ApproximatingIntegrals`). 

Since these rules are repeatedly used to approximate the integral $\displaystyle\int_{t_n}^{t_{n+1}} f(t, y(t))\,dt$, we know that there can be a difference between the numerical solution $ \tilde{y}_n $ and the exact solution $y(t)$.

Let us investigate this difference in an example.

::::{prf:example}
:label: Ex:ApproximatingSolutions:accuracy

Consider again the initial value problem

:::{math}

\left\{\begin{array}{rclll}
	y' & = & \frac7{10}\left(1-\frac{y}{750}\right)y-20, & \text{for} & t\geq 0, \\
	y(0) & = & 30.
\end{array}\right.

:::

We have applied each of the three methods to this initial value problem using several time steps.

Since the exact solution is known,

:::{math}
:label: Eq:ApproximatingSolutions:Solution

y(t)=\frac{150 \left(95 + \sqrt{9345} + \left(-95 + \sqrt{9345}\right) e^{\frac{1}{10} \sqrt{\frac{623}{15}} t}\right)}{483 + 5 \sqrt{9345} + \left(-483 + 5 \sqrt{9345}\right) e^{\frac{1}{10} \sqrt{\frac{623}{15}} t}}

:::

the error can be calculated for any time step $t_n$.

To compare the accuracy of the three methods we choose a point where they differ visibly from each other. From {numref}`Fig:ApproximatingSolutions:Euler1-t=15` it seems that $t=15$ is a good point to calculate the error for several values of $\Delta t$.

:::{applet}
:url: calculus/approximating_solutions/trapezoidal_method_2_with_exact
:name: Fig:ApproximatingSolutions:Euler1-t=15
:class: dark-light

The exact solution and the numerical approximations of the initial value problem from Equation {eq}`Eq:ApproximatingSolutions:EX2`.
:::

If $\tilde{y}_N$ is the approximation we obtain after $N=\frac{15}{\Delta t}$ steps, the absolute error is $|y(15)-\tilde{y}_N|$. We calculated the errors for different small values of $\Delta t$ at $t=15$. These results can be found in {numref}`Fig:ApproximatingSolutions:accuracy`.

:::{applet}
:url: calculus/approximating_solutions/absolute_errors
:name: Fig:ApproximatingSolutions:accuracy
:class: dark-light

Absolute error of different methods for different time steps.
:::

If you look at these errors, you can see that in the $\log-\log$ scale the errors seem to be linear functions of the time step for small values of $\Delta t$. In symbols this can be represented as

$$
\log|y(15)-\tilde{y}_N|=A+p\log(\Delta t),
$$

which we can rewrite to

$$
|y(15)-\tilde{y}_N| = C\Delta t^p.
$$

::::

We can generalise our observations to a definition and a theorem:

::::{prf:definition}
:label: Def:ApproximatingSolutions:Error

Assume $\tilde{y}_N$ is an approximation of $y(T)$ using a numerical time-integration method with time step $\Delta t$ and $T=t_0+N\Delta t$.

Then the **absolute error** $E(T,N)$ is defined as

$$
E(T,N) = \left|y(T)-\tilde{y}_{N}\right|.
$$
::::

::::{prf:theorem}
:label: Th:ApproximatingSolutions:accuracy

Assume $\tilde{y}_N$ is an approximation of $y(T)$ using a numerical time-integration method with time step $\Delta t$ and $T=t_0+N\Delta t$.

Then there exist a number $C>0$ and an integer $p$ such that

$$
E(T,N) \approx C\,\Delta t^p,
$$

where $p$ is independent of the function $y$.

::::

A proof of this theorem is too much for this course, but you can find it in {cite:t}`Vuik_2023`. In {prf:ref}`Th:ApproximatingSolutions:accuracy` the value of $p$ is independent of the solution $y$, which means that it only depends on the chosen method. As such, see {cite:t}`Vuik_2023`, we have the following results:

```{table} Order of accuracy of different time-integration methods.
:widths: auto
:align: center
:name: Tab:ApproximatingSolutions:order

|Method|$p$|
|-|-|
|Forward Euler|$1$|
|Backward Euler|$1$|
|Trapezoidal|$2$|
```

The number $p$ is so important, that we give it a name:

:::{prf:definition}
:label: Def:ApproximatingSolutions:order

The number $p$ in {prf:ref}`Th:ApproximatingSolutions:accuracy` is called the **order of accuracy** of the numerical time-integration method.
:::

{prf:ref}`Th:ApproximatingSolutions:accuracy` can not only be used to estimate the absolute error of a method when changing the value of the time step, but also the estimate the order of a method, which the next example shows.

::::{prf:example}
:label: Ex:ApproximatingSolutions:EstimateOrder

Consider the differential equation

$$
\left\{\begin{array}{rcll}
y' & = & f(t,y), & t\geq 0, \\
y(0) &=& 70.
\end{array}\right.
$$

We used some numerical time-integration method, of which we do not know the order, with two different values for $\Delta t$ to approximate the solution  $y$ of the initial value problem at time $T=8$. This gave us the following table:

```{table} Several errors.
:widths: auto
:align: center
:name: Tab:ApproximatingSolutions:EstimateOrder

|$\Delta t$|$N$|$E(8,N)$|
|-|-|-|
|$0.8$|$10$|$1.650$|
|$0.2$|$40$|$0.022$|
```

We can use these results to estimate the order $p$ of the method we used.

{prf:ref}`Th:ApproximatingSolutions:accuracy` gives that we have

$$
E(8,10)\approx C\left(0.8\right)^p,
$$

and also

$$
E(8,40)\approx C\left(0.2\right)^p.
$$

If we divide the first error by the second error, we find

$$
\frac{E(8,10)}{E(8,40)} \approx 4^p,
$$

or even better

$$
E(8,10) \approx 4^pE(8,40).
$$

Since we know both errors, we can try some value of $p$ in increasing order:

- If $p=1$, we would find $E(8,10)\approx4^1E(8,40) = 4\cdot0.022 = 0.088$, which is not really close to $E(8,10)=1.650$, so $p=1$ is unlikely.

- $p=2$ gives $E(8,10)\approx4^2E(8,40) = 16\cdot0.022 = 0.352$, which again deviates a lot from $1.650=E(8,10)$ and we ignore it further.

- Next $p=3$, which gives $E(8,10)\approx4^3E(8,40) = 64\cdot0.022 = 1.408$, which is pretty close to $1.650$, so is a likely candidate.

- To be sure, if $p=4$, we obtain $E(8,10)\approx4^4E(8,40) = 256\cdot0.022 = 5.632$, which is way larger than $1.650$ so $4$ is a too large value for the order of the method.

We conclude that $p=3$ is the most likely order of accuracy for the method we used.
